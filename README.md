# Your English Study Guide with Mr. Kenj

A General English study app for students: flashcards, word games, pronunciation practice and progress tracking, built on the Level A, B and C course material.

## Use it
The public site is https://tchmustafa74-cell.github.io/mr-kenj-english/

Open that link in any browser. This copy does not require a sign-in: all 90 lessons are available straight away. On a phone, choose **Add to Home Screen** (Safari) or **Install app** (Chrome) to use it like a regular app. After the first visit it also works offline.

## Publishing (GitHub Pages)
1. Push these files to the `main` branch.
2. In the repository go to **Settings → Pages**, set *Source* to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
3. After a minute the app is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- Each student's progress is saved in their own browser on their own device.
- Class features (homework hand-in to the teacher, the class progress/teacher view, and "Ask Mr. Kenj" sentence checks) rely on the shared signed-in version of the app and are hidden or inactive on this GitHub Pages copy.

## Files
- `index.html` — the whole app
- `manifest.json`, `icon*.png`, `icon.svg` — home-screen install
- `sw.js` — offline support
